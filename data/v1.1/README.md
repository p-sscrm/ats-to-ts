# v1.1 (current)

Current release of the MITRE ATT&CK to P-SSCRM mapping.

This directory provides two views of the mapping, each available in CSV and JSON:

- [`all/`](all/): Detailed mapping with per-strategy (M1–M4) flags, gap-task indicator, cross-strategy agreement field, and a `Manual v1.1 Mapping` field flagging pairings added by manual review (330 rows). See [`all/README.md`](all/README.md) for the full field schema.
- [`simple/`](simple/): Mapping of only MITRE ATT&CK techniques to P-SSCRM tasks (136 rows).

See the [root README](../../README.md#version-history) for how this version compares to v1.0.
